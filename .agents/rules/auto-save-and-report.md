# Auto Save, Log & Sync Rule

Every time a user request is addressed or code/assets are updated:
1. Ensure all edited files are securely written to disk.
2. Automatically record the new work details in today's work journal (`오늘_작업_일지_YYYY-MM-DD.md` and `TODAY_WORK_REPORT.md`).
3. Automatically synchronize changes with `school-release/` directory.
4. Keep the repository in a clean, deployable state.
