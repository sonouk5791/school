# 캐릭터 실제 녹음 파일 등록

실제 사람이 녹음하고 사용 권한을 확보한 MP3 또는 WAV 파일을 각 폴더에 추가합니다. 샘플 음성이나 AI 음성을 생성하지 않았습니다.

| 캐릭터 | 폴더 | welcome.mp3 녹음 대사 |
|---|---|---|
| 콩이 | kongi/ | 안녕하세요! 저는 콩이에요. 오늘도 저와 함께 천천히 몸을 움직여볼까요? |
| 토리 | tori/ | 반가워요! 저는 토리예요. 오늘 기분은 어떠세요? |
| 나비 | nabi/ | 안녕하세요. 저는 나비예요. 우리 같이 재미있는 기억 놀이를 해볼까요? |
| 보리 | bori/ | 안녕하세요! 저는 보리예요. 좋아하는 노래를 함께 들어볼까요? |

캐릭터별 파일:
- welcome.mp3: 환영 창, AI 친구 선택, 친구들 방, 오늘 프로그램 인사·날짜.
- activity.mp3: 오늘 프로그램 기분·체조·기억 활동.
- goodjob.mp3: 오늘 프로그램 마무리.

같은 이름의 WAV도 지원합니다. MP3가 있으면 먼저 선택합니다. 비어 있거나 헤더가 맞지 않는 파일은 목록에 포함하지 않습니다. 파일 헤더 확인은 녹음자의 신원이나 전체 파일의 디코딩을 보증하지 않습니다.

파일이 없는 상황의 버튼은 숨깁니다. 다른 상황 파일이나 TTS로 대체하지 않습니다. 페이지 자동 진입 시 재생하지 않으며 캐릭터 또는 듣기 버튼을 눌러 재생합니다.

로컬 서버는 파일 추가 후 창 포커스 또는 최대 30초 주기로 버튼을 갱신합니다. 운영 사이트에는 추가한 파일을 정상 배포하면 빌드가 목록을 자동 생성합니다. 별도 코드 수정은 필요 없습니다.

공유 컨트롤러 CharacterAudioPlayer가 기본 음량 0.7, 단일 재생, 일시정지, 다시 듣기, 화면 이탈 시 정지를 관리합니다. 기존 전체 환영 녹음과도 재생 시작 이벤트를 교환하여 겹치지 않게 합니다.
