# 🌸 기억정원 - 라일락마을 (Memory Garden : Lilac Village)

> **"함께라서 참 좋은 오늘! 언제나 든든한 우리의 보리와 함께하는 디지털 노인복지 플랫폼"**

치매 어르신과 주간보호센터 현장을 위한 어르신 친화형 디지털 인지·정서 케어 플랫폼입니다.  
푸근하고 든든한 곰돌이 캐릭터 **보리(Bori)**가 마을의 길잡이가 되어, 어르신이 디지털 기기에 대한 불안 없이 매일 즐겁게 신체 운동, 놀이, 두뇌 학습, 취미 활동을 즐길 수 있도록 돕습니다.

---

## 📌 주요 특징 (Key Features)

### 1. 🐻 메인 캐릭터 「보리」와 함께하는 인터랙션
- **든든하고 다정한 안내자:** 갈색 털과 둥근 귀, 푸근한 미소와 은은한 볼홍조를 지닌 든든한 곰돌이.
- **상징 의상:** 시인성이 높은 **코발트 블루 후드티**와 가슴 정중앙의 **희망 새싹 로고**.
- **다정한 음성 안내 (TTS):** 화면 접속 시 및 활동 선택 시 다정한 한국어 음성으로 어르신에게 말을 건넵니다.
- **무실패(No-Fail) 원칙:** 점수나 실패의 압박 없이 끊임없는 칭찬과 격려를 제공합니다.

### 2. 🏡 라일락마을 4대 핵심 활동 공간
1. **🏃 기운찬 운동방 (Green):** 의자 체조, 가벼운 스트레칭, 박수 놀이로 신체 활력 증진
2. **🧩 오순도순 놀이방 (Orange):** 추억의 물건 카드 짝맞추기, 그림자 퍼즐로 단기 기억력 및 집중력 강화
3. **📖 또박또박 학습방 (Blue):** 추억의 동요·가요 빈칸 채우기, 시장 바구니 셈하기로 인지 자극
4. **🎨 꽃피는 취미정원 (Purple):** 원터치 수채화 컬러링, 옛 LP 음악 감상, 보리와의 옛 추억 회상

### 3. 👵 어르신 친화적 UI/UX 설계 원칙
- **초대형 원터치 타깃:** 높이 110px 이상의 큼직한 버튼, 드래그/스와이프 없는 100% 단순 탭 방식.
- **고대비 & 파스텔 정원 톤:** 눈부심 없는 아이보리/라일락 배경과 높은 시인성의 방별 테마 색상.
- **시청각 피드백:** 버튼 터치 시 청량한 실로폰 차임벨 사운드(Web Audio API) 및 음성 가이드 제공.
- **단순한 화면 깊이 (Depth):** 최대 2단계 이내 구성 및 상시 [🏡 처음으로] 버튼 고정.

### 4. 📋 주간보호센터 사회복지사 편의 기능
- **스마트TV 단체 미러링 모드:** 센터 내 대형 화면을 통한 10~20인 단체 체조 및 노래 교실 지원.
- **선생님 호출 벨:** 어르신이 어려움을 느낄 때 원터치로 담당 복지사를 호출하는 안심 기능.
- **글씨 확대 토글:** 저시력 어르신을 위한 원클릭 폰트 확대 모드.

## 🚀 로컬 실행 방법

별도의 복잡한 설치 없이 모든 최신 웹 브라우저(Chrome, Edge, Safari 등)에서 즉시 구동됩니다.

### 옵션 1. Python 로컬 서버 실행 (권장)
```bash
python -m http.server 8080
```
브라우저 주소창에 `http://localhost:8080/index.html` 접속

### 옵션 2. 브라우저로 직접 열기
`index.html` 파일을 더블 클릭하여 실행

## 🎨 캐릭터 스타일 가이드 요약 (Bori Style Guide)

- **등신비:** 2.5 ~ 2.7등신 (안정적이고 듬직한 체구)
- **얼굴:** 하단 볼살이 도톰한 둥근 찹쌀떡 형태 + 둥근 반원형 귀 + 은은한 복숭앗빛 볼홍조
- **의상:** 코발트 블루 후드티 (`#2B6CB0`) + 가슴 중앙 연두색 새싹 로고 (`#8BC34A`) + 캥거루 주머니
- **메인 컬러:** 
  - 바디 털: Warm Teddy Brown (`#A06A3F`)
  - 주둥이: Soft Cream Beige (`#F2DFCA`)
  - 의상: Cobalt Blue (`#2B6CB0`)
