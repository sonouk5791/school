# 캐릭터 방 꾸미기

2026-09-22 업데이트

## 사용 흐름

- 콩이·토리·나비·보리 방을 고르면 각자의 기본 색상과 소품을 표시합니다.
- 쉬운 꾸미기는 한 주제에 4개, 자유 꾸미기는 한 페이지에 최대 6개 선택지를 표시합니다. 나머지는 ‘다른 것 보기’로 선택합니다.
- 커튼, 러그, 벽지, 바닥, 방 구조, 가구와 장난감은 선택 즉시 반영됩니다.
- 캐릭터 옷, 부위별 색상, 액세서리, 표정, 손에 드는 소품도 기존 실시간 편집기로 변경됩니다.
- ‘내 방 저장하기’로 저장하면 다시 방문할 때 마지막 방과 네 캐릭터의 꾸민 상태를 복원합니다.
- ‘기본 방으로 되돌리기’는 현재 방과 해당 캐릭터만 초기화합니다. 되돌리기로 취소할 수 있습니다.

## 구현과 호환성

- `js/room-decor.js`: 주제 선택, 페이지 나누기, 테마, 커튼·러그 레이어.
- `js/character-house.js`: 방별 상태, 저장·복원·되돌리기, 가구 배치.
- `js/house-furnishings.js`: 기존 SVG 가구와 침대·미끄럼틀·텐트·캐릭터별 소품.
- `js/character-customizer.js`: 원본 캐릭터 이미지 위 의상·표정·액세서리 레이어.
- 저장 키 `senior_character_house_data_v1`은 유지합니다. `schemaVersion: 2`의 `rooms` 객체에 캐릭터별 방을, `customizations`에 캐릭터별 모습을 저장합니다.
- 기존 단일 방 데이터는 해당 캐릭터 방으로 이관하며 기존 소품과 의상 기록을 보존합니다.
- 곰 캐릭터 표시 이름은 보리로 통일합니다. `bori` 식별자와 기존 ‘곰이’ 음성 호출 별칭은 호환성을 위해 유지합니다. 기존 녹음 파일은 재녹음하지 않았습니다.
- 저장은 현재 브라우저의 localStorage를 사용하므로 다른 기기로 자동 공유되지 않습니다.

## 검증

- `tests/room-decor.cjs`: 네 방 독립 저장, 테마, 실시간 변경, 초기화·되돌리기, 이전 저장 데이터 이관.
- `tests/character-house-layout.cjs`: 1440/1024/768/390px 레이아웃과 저장·복원.
- `tests/character-customizer.cjs`: 네 캐릭터 의상·색상·액세서리·표정·소품, 기본 모습 복귀와 저장·복원.
- 작은 화면에서 버튼 클릭이 방 미리보기에 가려지지 않는지 검증했습니다.
