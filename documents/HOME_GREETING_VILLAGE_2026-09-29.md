# 메인 인사영상 · 친구들 마을 수정 결과 — 2026-09-29

## 구현
- 첫 화면의 재생/소리 듣기 버튼을 제거하고 `🏡 바로 친구들 마을로 가기` 버튼(높이 64px 이상)을 표시합니다.
- 영상은 소리 포함 재생을 먼저 시도하고, 거절되면 음소거로 다시 시도합니다. 사용자가 저장해 둔 전체 음소거 설정은 우선 존중합니다. 두 번 모두 차단되면 포스터와 마을 이동 버튼을 표시합니다.
- 이동 버튼은 같은 클릭 처리에서 `video.pause()`와 세션 저장을 실행합니다. 실제 `ended` 이벤트 또는 이동 버튼으로 400ms fade out 후 400ms fade in합니다. 동작 줄이기 설정에서는 즉시 전환합니다.
- `sessionStorage.school_home_intro_played=true`와 기존 history 상태를 사용합니다. 같은 탭의 뒤로가기/새로고침/방에서 복귀 시 마을을 표시하고, 보조 버튼으로 영상을 처음부터 다시 볼 수 있습니다.
- 영상 로딩 오류는 `인사 영상을 불러오지 못했어요.`와 포스터/마을 이동 버튼으로 처리합니다. 늦게 도착한 재생 실패가 마을 이동 후 영상을 재시작하지 않도록 요청 번호를 확인합니다.
- 기존 음성 관리자의 중지/음성 시작 이벤트를 유지하여 영상과 별도 음성이 겹치지 않게 합니다.

## 검증 결과
- `home-autoplay.cjs`: PASS. 1920×1080, 1366×768, 768×1024, 390×844에서 자동재생, 실제 ended, 네 집 이동·뒤로가기·새로고침, 다시 보기, 즉시 pause, 세션 저장, 64px 버튼, 가로 넘침/JS 오류 없음. 소리 차단/전체 차단/저장된 음소거/지연 거절/404도 확인.
- `village-walk.cjs`: PASS. 네 크기에서 단일 마을, 투명한 집 영역, 말풍선·역할·장면·버튼 비겹침, 큰 버튼. 전체 화면 캡처를 직접 검토했습니다.
- `home-flow-resilience.cjs`: Edge와 Chrome 모두 PASS. 키보드 이동/다시 보기/집 포커스, 동작 줄이기, 원본 이미지 경로/외곽 경로, 인사 중 TTS 호출 없음, 다른 음성·선생님 이동 시 영상 중지.
- Edge/Chrome 새 브라우저 세션은 첫 방문의 소리 있는 autoplay를 차단하여 무음으로 재생했습니다. 사용자 클릭/Enter 후 다시 보기는 음소거 없이 재생됐고 오디오 디코딩 바이트 증가를 확인했습니다.
- JS 구문검사, 녹음 manifest 빌드, `commercial-security-source.cjs` PASS.
- API는 브라우저 회귀검증에서 실패 응답으로 격리했습니다. 실제 계정/DB 쓰기나 유료 TTS 호출을 테스트하지 않았습니다.
