# 우리 집 · 텃밭 · 이웃 방문 구현 기록

## 변경 사항

- 기존 마을 하단에 `우리 집`, `이웃집 둘러보기` 진입을 추가했다. 기존 인사 영상, 네 캐릭터 방, 수업·꾸미기·기록 기능을 보존했다.
- `our-home.html`은 기와집, 작은 문, 낮은 담장, 꽃, 나무, 벤치와 장독대 느낌을 코드로 표현한다. 공식 캐릭터 데이터의 idle PNG와 기존 Google/Gemini 캐릭터 음성 연결을 재사용한다.
- 여섯 밭, 여섯 채소, 심기 확인, 물주기, 돌보기, 4단계 성장, 오늘의 수확 바구니, 채소 퀴즈, 채소별 회상 질문을 제공한다.
- 실제 날짜 모드는 한국 날짜 기준 심은 날부터 4일째 수확한다. 수업 모드는 2분마다 성장하여 약 6분에 수확하며, 물주기와 돌보기가 필요하다. 기다리는 동안 `자란 모습 확인하기`로 현재 상태를 확인한다.
- 물주기는 본인 밭 하루 한 번, 이웃 도움은 방문자·대상·밭·날짜별 한 번이다. 물을 반복해서 눌러 성장 시간을 줄일 수 없다.
- 이웃 방문은 기본 OFF다. 선생님이 준비하고 허용한 집만 표시하며, 방문 확인과 정해진 인사말을 제공한다.

## 데이터 및 권한

- 기존 `school_operations` PostgreSQL JSON 문서 안에 `garden.homes`, `garden.sessions`, `garden.events`를 추가한다. 기존 테이블·데이터를 덮어쓰거나 초기화하지 않는다.
- 관리자는 기존 서버 인증을 거쳐 어르신별 집과 모드를 설정하고 이 기기에 사용할 어르신을 연결한다. 모드 변경은 자라는 채소가 없을 때만 가능하다.
- HttpOnly/SameSite 쿠키와 서버에 저장된 토큰 해시로 본인을 결정한다. 클라이언트가 보낸 대상자 ID를 본인 인증으로 사용하지 않는다. 세션은 8시간 후 만료한다. 공유 기기는 사용자 변경 때 선생님이 다시 연결한다.
- 이웃 응답은 별칭, 집 식별자, 텃밭 상태만 화이트리스트로 구성한다. 생년·등급·건강·메모·가족·수업 기록은 포함하지 않는다. 상세 방문 기록은 관리자 인증을 요구한다.
- 방문자는 보기·물주기 도움·정해진 인사만 가능하며 심기·수확·변경·초기화는 서버에서 차단한다. 방문 허용 취소는 다음 API 요청부터 적용된다.
- 트랜잭션 내 상태 검사로 중복 물주기를 막고, 활동 UUID로 응답 유실 후 같은 저장 재시도를 중복 처리하지 않는다.
- 방문 및 활동 이벤트는 상세 로그에 남기고, 기존 참여 기록에는 대상자별 하루 한 행으로 모아 클릭 수가 수업 횟수로 부풀려지지 않게 한다. 활성 화면 시간을 기록하며 실제 신체 참여나 표정·기분을 추측하지 않는다.
- 기존 일지 초안 및 주간·월간 합계와 연결했다. 생활 활동 시간을 별도로 합산한다. 수확·회상 완료 시 JOURNAL_MODEL이 설정되어 있으면 기존 자동화 엔진의 AI 일지 작업에 등록한다. 선생님 확인·편집 절차를 유지한다.

## 현재 운영 제한

- 운영 PostgreSQL 연결은 아직 없다. 따라서 현재 공개 화면은 **개인정보 없는 익명 체험**, 같은 기기의 localStorage 저장이다. 실제 어르신별 저장과 이웃 방문은 활성화하지 않는다.
- 실제 운영에는 기존 DATABASE_URL, 관리자 초기 인증, schema.sql 적용 및 서버 세션 연결이 필요하다. 비밀값은 문서나 Git에 기록하지 않는다.
- AI 생성은 JOURNAL_MODEL과 기존 Google 인증, 자동화 호출 설정 이후 실제 동작 검증이 필요하다. 연결 전에는 사실 기반 기록 요약 초안을 사용한다.
- 실제 Google 음성 합성, 운영 DB의 동시 트랜잭션, 실제 Android/iPhone은 이번 환경에서 검증하지 않았다. 음성 실패와 무관하게 모든 안내는 텍스트로 제공한다.
- 단체 수업 텃밭, 꽃 심기·청소 등 마당 확장, 계절별 자산 교체는 이번 단계에 추가하지 않았다. 현 데이터와 별도 페이지 구조를 확장할 수 있다.

## 검증

- `tests/garden-domain.cjs`: 한국 날짜 4단계 성장, 6분 체험 성장, 저장 복원, 물주기 제한, 방문자 금지 동작, 공개 응답 필드.
- `tests/garden-api.cjs`: 실제 API 핸들러 + 트랜잭션 테스트 대역. 관리자/개인 세션, 본인 판별, 개인정보 제외, 중복 저장, 권한 철회, 초안 누적. 운영 DB 시험은 아니다.
- `tests/garden-browser.cjs`: Edge 1920×1080 / 1366×768 / 768×1024 / 390×844에서 심기 확인, 새로고침, 물주기 제한, 수확, 퀴즈, 회상, DB 미연결 안내, 가로 넘침·버튼 크기·브라우저 오류 점검. 6분 경과는 테스트 데이터의 심은 시각을 앞당겨 검증했다.
- `tests/garden-cloud-browser.cjs`: 실제 UI + API 핸들러 + 저장소 대역으로 관리자 설정/기기 연결 → 방문 확인 → 물주기 도움 → 축하 인사 → 기록 → 본인 집 복귀.
- 기존 `operations-domain`, `operations-api`, `home-autoplay`, `village-walk` 회귀 검사 통과.
