# 메인 인사 영상 및 친구방 흐름 변경 — 2026-09-28

- 요청: 수업 선택 카드 대신 제공 MP4 → 실제 영상 종료 → 네 친구 소개 및 방 선택 흐름.
- 제공한 다운로드.mp4를 assets/videos/home-greeting.mp4에 원본 그대로 복사하고 첫 장면 poster를 추가했다. SHA256: 124770B7C5275A91D11507EC20C1792F4B733741DCBA7063C197CD2951433A08.
- 기존 네 친구 원본 이미지, 얼굴, 방 링크를 재사용했다. 새 캐릭터 생성 및 원본 수정은 없다. 기존 손 좌표로 손 영역만 분리해 가볍게 인사한다.
- 사용자 클릭으로 재생하며 자동/반복 재생은 꺼져 있다. 실제 ended 이벤트에서 400ms씩 fade out/in한다. 시간 경과만으로 영상을 건너뛰지 않는다.
- 콩이→토리→나비→보리 순서로 소개한다. 언제든 방을 선택할 수 있다. 기존 캐릭터 음성 API를 사용하며 음성 실패 시 텍스트 소개를 유지한다. 이동/재생/숨김 시 이전 음성을 중지한다.
- 영상 건너뛰기, 다시 보기, 음소거, 로딩 실패 안내, 뒤로가기 시 친구방 복귀를 제공한다.
- 오전/오후/간편 수업은 선생님 공간 및 접힌 오늘의 수업 메뉴로 유지했다. 기존 활동 목록, 집 꾸미기, 저장 데이터, 자동화 및 TTS 설정을 보존했다.

## 검증
- 실제 MP4 재생/종료 전환, 순차 소개, 소개 중 방 선택, 네 방 링크, 뒤로가기/다시 보기/건너뛰기, 일시정지 중 자동 전환 방지, 영상 404 실패 탈출: 통과.
- 1920×1080 / 1366×768 / 768×1024 / 390×844: 4/4/2/1열, 가로 넘침 없음.
- 음성 API 실패 시 네 친구 텍스트 소개, reduced motion, 키보드 재생, 선생님 공간 진입 시 영상 정지: 통과.
- 오전/오후 정규 수업, 선생님 인증, 운동방 상태 흐름, 기존 콩이 영상 회귀 테스트: 통과.
- 원본 이미지/저장 데이터 유지 확인. JS 문법 검사 통과.
- 브라우저 검증은 Edge 자동화의 화면 크기별 테스트다. 실제 모바일/태블릿 기기 테스트는 하지 않았다.
- 실제 Google 음성 합성은 로컬 서버 인증 환경이 없어 검증하지 않았다. 기존 음성 연결 유지 및 실패 대응은 테스트했다. 운영 DB 미연결 상태는 이번 요청 범위 밖의 기존 제한이다.
