# 디지털 AI 학교 작업 종합 기록

작성일: 2026-09-22

## 보존 원칙

기존 캐릭터 디자인, 활동 콘텐츠, 문제 데이터, URL, 저장 데이터와 관리자 기능을 보존하며 필요한 UI와 상태 흐름만 점진적으로 수정했습니다. 사용자 공통 작업 원칙을 AGENTS.md에 추가했습니다.

## 선행 작업

- 네 캐릭터의 실시간 의상·색상·액세서리·표정·소품 편집, 기본 모습 복귀와 저장/복원.
- 콩이·토리·나비·보리별 방 테마, 커튼·러그·가구·소품 실시간 반영과 방별 독립 저장. 기존 단일 방 데이터를 이관하고 보리 표시 이름을 통일했습니다.
- 사용자 첨부 원본 이미지를 그대로 사용한 네 친구 중심 홈페이지 Hero. 운동·놀이·학습·취미 기존 URL에 연결했습니다.
- 체조 카드 HTML/CSS 클래스 불일치로 인한 이미지 넘침과 좁은 설명문 수정. 전체 프레임 contain 표시와 자연스러운 한글 줄바꿈.
- 위 선행 변경은 GitHub 커밋 18666b6 및 Vercel 운영 배포에서 확인했습니다.

## 1차: 메인 중복 진입 통합

네 친구와 추천 활동 하나를 핵심으로 남겼습니다. 기존 메뉴·아침 프로그램·기분 선택 등의 진입을 전체 활동으로 이동했습니다. AI 교육과 시니어 인지활동은 각각 접힌 영역으로 묶었습니다. 기존 수업 카드 14개와 이벤트를 유지했고, 기존 warmupReplay 요소 부재로 발생하던 콘솔 오류를 수정했습니다.

주요 파일: index.html, js/home-character-hero.js, css/home-character-hero.css, js/senior-finish.js, js/warmup-intro.js.

## 2차: 상단 및 접근성 도구

홈·소리·보기·도움·선생님 공간으로 상단을 구성했습니다. 글씨·속도·고대비는 보기 패널에서 기존 설정 키와 이벤트를 재사용합니다. 활동별 재생 도구와 관리자 일지는 보존하고, 집 꾸미기는 캐릭터별 활동방에서 진입하도록 연결했습니다.

주요 파일: js/home-accessibility-menu.js, css/home-accessibility-menu.css, index.html 및 네 활동방 HTML.

## 3차: 토리·나비·보리 활동 상태 분리

select → playing → completed의 공통 표시 상태를 추가했습니다. 입장 시 네 선택지, 진행 시 선택한 패널 하나, 완료 조건 충족 후 완료 UI를 표시합니다. 기존 문제 생성과 도장·저장 처리, 재시작/다음 버튼은 유지했습니다. 활동을 떠난 뒤 실행되는 지연 콜백을 차단하고 노래 타이머와 음성을 정리합니다.

주요 파일: tori-play.html, nabi-learn.html, bori-hobby.html, js/room-activity-flow.js, css/room-activity-flow.css.

## 4차: 콩이 운동 상태와 완료 판정

ready → playing → completed를 명확히 표시하고 시작 버튼은 하나, 운동 조작은 이전·쉬기·다음·다시 듣기·천천히 중심으로 정리했습니다. 기타 기능은 접힌 설정에 보존했습니다. 마지막 동작 종료 시 건너뛴 동작까지 완료되던 문제를 수정해 실제 재생 시간에 따라 체크하며, 미완료 동작은 이어서 진행합니다. 기존 10개 콘텐츠는 유지했습니다.

주요 파일: senior-exercise.html, css/senior-exercise.css, js/senior-exercise.js.

## 5차: 쉬운 방 꾸미기

벽지 → 커튼 → 러그 → 가구 → 소품 → 옷 → 완료의 7단계로 구성했습니다. 단계당 3~4개 선택과 즉시 반영, 이전/다음 이동을 제공합니다. 가구·소품은 단계별 슬롯으로 교체해 중복 누적을 줄였습니다. 상세 편집 도구는 쉬운 모드에서 숨기고 자유 모드와 데이터를 공유합니다. 기본 방 복귀에는 아니요/네 확인을 추가했습니다.

주요 파일: character-house.html, js/character-house.js, js/room-decor.js, css/character-house.css.

## 6차: 오늘의 20분 활동

메인의 단일 추천 영역에서 진입합니다. 기존 운동·놀이·학습·취미 페이지를 한 번에 하나씩 불러와 각 5분간 참여합니다. 명시적인 다음 활동, 이전 단계, 쉬기, 저장 후 종료를 제공합니다. 날짜·학습자별 단계와 참여 시간을 저장하고 이어서 할 수 있습니다. 모든 단계 완료 시 기존 digital_school_care_records에 날짜·학습자별 한 번만 완료 기록을 추가합니다.

이는 각 원본 콘텐츠의 전체 완주가 아니라 각 방에서의 5분 참여 기준입니다. 새로운 문제나 대량 콘텐츠를 생성하지 않았습니다.

주요 파일: daily-course.html, js/daily-course.js, css/daily-course.css, index.html.

## 음성 시스템: 준비 완료, 실제 연결 미완료

js/character-voice-system.js에 네 고정 음성 ID 검증, 캐릭터별 속도와 문장 쉼, 중복 요청 억제, 취소 및 공통 제어 구조를 준비했습니다. 실제 Typecast 음성 목록 조회는 인증 401로 실패했습니다. 유효한 서비스 설정과 실제 음성 네 개 선정/청취, provider 및 페이지 연결은 아직 완료되지 않았습니다. 준비 모듈은 실제 페이지에 연결하지 않았습니다. 상세: CHARACTER_VOICE_SETUP.md.

## 검증 및 한계

- 네 캐릭터 커스터마이징과 방 저장/복원, 자유 모드, 초기화 확인을 검증했습니다.
- 메인 기존 수업 실행, 활동 기록 화면/홈 복귀, 모바일·태블릿 가로 넘침, 접근성 상태 저장과 키보드 닫기를 확인했습니다.
- 세 방의 12개 활동 선택/복귀, 나비 날짜 실제 정답 후 완료/재시작 및 지연 완료 취소를 확인했습니다.
- 운동 완료 판정은 테스트 응답의 동작 시간을 줄여 검증했습니다. 원본 데이터는 변경하지 않았습니다.
- 20분 코스는 저장 시간을 종료 직전으로 준비한 테스트에서 네 단계 순서와 기록 중복 방지를 확인했고, 실제 시간 흐름으로 쉬기와 중간 복원을 검증했습니다.
- 실제 12분 운동 및 20분 코스 전체 시간 완주, 모든 문제의 전체 완주 검증은 남아 있습니다.
- 기존 쉬운 모드 카테고리/페이지 수를 가정한 자동 테스트는 새 7단계 기준으로 갱신이 필요합니다.
