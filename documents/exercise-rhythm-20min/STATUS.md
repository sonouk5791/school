# 20분 건강체조 제작 상태

상태: **미완성 — 연결된 Runway 무료 요금제에서 영상 생성 불가**

Runway 재인증은 승인되어 연결을 확인했습니다. 현재 연결된 무료 요금제에서 사용 가능한 영상 모델은 0개이며, 다른 연결 가능 워크스페이스도 없습니다. 새 운동 영상이나 완성 MP4는 생성되지 않았습니다.

## 확보·검증한 자료

- 사용자 요청 원문은 REQUEST.md에 보존했습니다.
- 요청문을 그대로 분리한 30구간: 총 1,200초, 빈 구간·겹침 없음, 각 20~60초.
- 공식 캐릭터 4명의 참조 경로를 manifest에서 확인했습니다.
- 다운로드 폴더의 같은 곡명/번호 MP3: 약 52.15초, 48kHz 스테레오. 전체 디코딩 검사 통과. 이후 사용자가 동일한 실제 MP3 경로를 직접 지정하여 제작 음악을 확인했습니다. 로컬 제작 폴더에 복사하고 SHA-256 일치를 확인했습니다.
- 음악 박자·운동 동기화, 음성, 클립, 최종 영상 검증은 아직 수행하지 않았습니다.

## 보존 및 배포

기존 홈페이지·캐릭터·운동 영상·TTS·저장 로직은 수정하지 않았습니다. 이전 검수 탈락 리깅이나 기존 영상을 새 완성본으로 사용하지 않습니다. 영상 생성 요금제 제한으로 작업 미완료이며 GitHub 푸시와 Vercel 배포는 수행하지 않습니다. 제작표와 작업 기록만 릴리즈 폴더에 동기화합니다.

- 사용자 제공 원본 PNG 4장(보리·나비·토리·콩이)을 로컬 제작 폴더에 원본 바이트 그대로 보존하고 해시와 크기를 기록했습니다. 홈페이지 공식 캐릭터 파일은 교체하지 않았습니다.

- 캐릭터 이름 통일, a홉→아홉 수정, 효과를 단정하는 문구를 격려 표현으로 정리한 30구간 NARRATION_DRAFT.md를 작성했습니다. 최종 음성은 아직 없습니다.
