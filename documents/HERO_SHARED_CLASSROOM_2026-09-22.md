# Hero 공통 교실 공간 정리 — 2026-09-22

## 변경
- 흰색 공통 카드/개별 hover 흰 카드 대신 크림 벽, 베이지 바닥, 연한 초록 창문·식물 CSS 실루엣으로 구성.
- 원본 JPG와 팔/손 애니메이션은 보존. 홈에만 SVG 윤곽 clip을 적용해 외부 흰 여백과 바닥 그림자를 최소화. 흰 얼굴·의상 내부 픽셀은 원본 유지.
- 네 캐릭터 동일 viewBox 크기, 중앙 정렬 및 발 기준 y=626 정렬. 토끼 긴 귀 등 원래 비율은 유지.
- 동일 크기/색/불투명도 ground shadow 적용. 이름 아래 노랑/분홍/보라/파랑 포인트만 추가.
- PC 4열, 태블릿·모바일 2열. 좁은 화면에서는 두 행 각각 공유 바닥 표시.
- 기존 이름/활동 링크/추천/음성/기록 보존. 방 화면은 이번 홈 윤곽·배경 변경 대상이 아님.

## 파일
- css/home-character-hero.css
- js/hero-contours.js (원본 윤곽 좌표, raster 이미지 추가 없음)
- js/character-animation.js (홈 SVG에만 윤곽 및 정렬/그림자 적용)
- index.html (윤곽 설정 로드)

## 검토
PC 1280px / 모바일 390px 화면 캡처 검토, 모바일 가로 넘침 없음. 원본 raster 파일 변경 없음. 윤곽 마스크는 JPEG 기반 수동 좌표이므로 전용 투명 원본이 제공되면 가장자리와 관절 경계를 더 정밀하게 개선 가능.
