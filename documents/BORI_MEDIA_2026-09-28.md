## 4. 추억극장

보리 취미방 → 영상 고르기 → 대상자 선택(또는 체험) → 재생 → 회상 → 기분 선택 → 기록·일지 초안.

- 큰 영상, 재생·일시정지·다시보기·소리 크게/작게·크게 보기·감상 마치기.
- 로딩 안내와 표시, 재생 실패 시 재시도/다른 영상/홈.
- 실제 `ended` 이벤트 후 회상 화면. 자동 다음 단계 OFF이면 현재 화면에서 사용자의 다음 선택을 기다림. 설정은 기기에 보존.
- 정답을 요구하지 않는 기억·모름·이야기 의사 선택. ‘이야기하고 싶음’을 ‘적극적 대화’로 바꾸지 않음. 실제 적극적 대화/반응 없음은 선생님 관찰 입력으로만 기록.
- 중단 시 실제 시청 시간과 재생 위치 보존. 다음 진입에서 이어보기/처음부터 선택.

## 5. 옛 노래 교실

- MP4, MP3, WAV, HTTPS 주소, 지원하는 공식 임베드 영상.
- 영상·음원 시간에 맞춰 등록 가사 1~2줄 표시. 32~44px, 큰 글씨 설정에서는 44px.
- 재생/쉼/다시 부르기, 0.75·1배 속도, 소리 조절, 큰 화면, 현재 시간/전체 시간/진행률.
- 재생 종료 후 감사 안내와 기분 선택. 중도 종료는 완료 칭찬 대신 쉬기 안내.
- 한 번 더 부르기 횟수 기록. 추억 이야기·색칠·다른 콘텐츠·보리 홈으로 이동.
- 여러 대상자는 반응을 알려줄 대상자를 선택한다. 한 명의 기분을 다른 사람에게 복사하지 않는다.
- 보리 안내는 기존 `CharacterVoice`와 Google TTS를 재사용하며 영상 재생을 시작하면 안내 음성을 멈춘다.

## 6. 영상 저장 방식

| 방식 | 저장/재생 위치 | 범위 |
|---|---|---|
| 직접 업로드 MP4/MP3/WAV | 브라우저 IndexedDB `school-bori-media-files` | 최대 200MB, 등록한 브라우저·기기 전용 |
| 기관 보유/외부 스토리지 | 관리자가 등록한 HTTPS 주소에서 직접 재생 | Firebase/Supabase/Cloudinary 등에 이미 보유한 재생 가능한 주소 사용 |
| 공식 임베드 | YouTube IFrame Player API | 임베드 허용 영상만. 임의 HTML/스크립트/iframe 입력은 받지 않음 |
| 콘텐츠 메타데이터 | 현재 localStorage, DB 연결 시 PostgreSQL JSONB | 원본 미디어 바이너리를 PostgreSQL에 넣지 않음 |

**현재 클라우드 업로드 서비스는 연결되어 있지 않다.** 직접 업로드는 서버 업로드가 아니다. 다른 기기에서도 사용할 자료는 기관 저장소 주소를 등록해야 한다. 브라우저 데이터를 지우면 로컬 파일이 없어질 수 있으므로 기관 원본을 별도 보관한다. 다른 기기에 로컬 blob 주소를 배포하지 않는다.

## 7. 가사 데이터

관리자가 직접 입력한 구간만 사용한다. 시간 겹침·역순·빈 문구·3줄 이상을 검증한다. 500구간 이하, 구간별 120자 이하이며 시작·종료는 초 단위다.

```json
{
  "id": "media-example",
  "kind": "song",
  "title": "기관 등록 노래",
  "videoType": "mp3",
  "videoUrl": "https://기관저장소/권한확인음원.mp3",
  "enabled": true,
  "rightsConfirmed": true,
  "lyricsRightsConfirmed": true,
  "lyrics": [
    { "start": 0, "end": 8, "text": "관리자가 입력한 첫 안내" },
    { "start": 8, "end": 16, "text": "관리자가 입력한 다음 안내" }
  ]
}
```

위 문구는 설명용 예시이며 실제 노래 가사가 아니다. `currentTime`을 기준으로 표시하므로 일시정지·구간 이동·배속 변경과 함께 움직인다. 좁은 화면에서는 등록 문구를 실제 글자 폭에 맞춰 두 줄씩 나누어 같은 구간 안에서 표시한다. 빠르게 넘어가지 않도록 관리자는 짧은 문구와 충분한 표시 시간을 등록하는 것이 좋다.

## 8. 기록과 AI 일지

- 기기 저장 키: `school_bori_media_v1` (`contents`, `records`, 동기화 표시), `school_bori_resume_theater`, `school_bori_resume_song`.
- 기록: 콘텐츠 ID/제목/종류, 대상자 ID, 시작/종료, 실제 재생 초, 마지막 위치, 전체 길이, 완료 여부, 다시보기 횟수, 대상자별 반응/기분, 선생님 메모.
- 재생 중인 시간만 참여 시간에 더한다. 일시정지·버퍼링·숨겨진 탭은 제외한다. 재생 위치를 앞으로 옮겼다고 시청 시간이 늘어나지 않는다. 실제 재생 시간은 음소·표정·노래 참여를 관찰한 결과와 다르므로 참여도나 표정을 자동 판정하지 않는다.
- 기기에서 5초 간격 및 상태 변경 시 저장. 중단 시 참여 시간도 저장.
- 단독 활동은 기존 `OperationsStore`의 세션/개인 참여 기록/확인 대기 일지에 연결한다. 대상자를 고르지 않은 체험은 개인 일지를 임의로 만들지 않는다.
- 정규 수업 안에서는 감상 결과를 부모 수업에 합친다. 별도 세션을 만들어 전체 수업과 감상 시간을 중복 집계하지 않는다.
- 선생님 공간의 콘텐츠 관리에서 최근 30개 감상 기록에 메모·관찰 반응을 추가할 수 있다. 기존 일지·보고서 화면에서 문장을 수정하고 검토한다. 이전 기록 데이터는 삭제하지 않는다.
- **현재 DB/AI 모델 연결이 없으므로 실제 외부 AI 생성은 미실행이다.** 지금 확인 가능한 일지는 사실 기반 기록 요약 초안이다. 기존 서버 Google AI 일지 경로에는 기록의 콘텐츠·시간·반응·메모가 전달되도록 연결했다.

## 9. 자동화 연결

`BORI_MEMORY_THEATER`, `BORI_OLD_SONG_CLASS`를 보리 프로그램 후보에 추가했다. 유효하고 사용 중인 콘텐츠가 있는 종류만 신규 편성 후보로 활성화한다. 기존 승인·미승인 구분은 유지한다.

승인한 오후 편성 → 해당 보리 페이지 → 대상자 연결 → 감상·회상 → 원래 수업 마무리/평가/일지로 이어진다. 감상 중 3분마다 iframe이 교체되지 않으며 부모 수업을 멈추면 미디어도 멈춘다. 원래 60분 총 수업 타이머는 유지한다.

오늘 추천은 최근 7일 감상 이력을 우선 제외한다. 후보가 모두 사용됐으면 활성 콘텐츠 안에서 날짜별로 순환한다. 현재 DB 미연결 상태에서는 이력이 기기별이므로 여러 기기의 추천을 하나로 통합하지 않는다. 기존 서버 예약 실행은 계속 연결 대기 상태다.

## 10. 추가 설정

1. 선생님 공간 → 영상·음악 콘텐츠 관리에서 합법적 미디어를 등록한다. 기본 콘텐츠는 비어 있으며 빈 검은 플레이어 대신 준비 안내를 보여준다.
2. 클라우드 공유가 필요하면 이전 운영 문서의 PostgreSQL·관리자 인증을 연결한다. 새 JSONB 키를 사용하므로 기존 스키마를 삭제하지 않는다. 로그인한 서버 세션으로 콘텐츠와 감상 기록을 동기화한다.
3. 기관 스토리지에 업로드한 파일은 브라우저에서 직접 재생 가능한 HTTPS 주소여야 한다. 공급자 정책·접근 만료·Range 요청·MIME·해당 코덱 지원을 확인한다.
4. 실제 Google AI 일지는 기존 `JOURNAL_MODEL`/Google 권한 설정과 검증이 필요하다. TTS 설정은 변경하지 않았다.
5. 엄격한 기관 예약 운영은 이전 문서의 DB 및 서버 스케줄러 설정이 필요하다. 이번 작업에서 새로운 유료 서비스나 비밀값을 생성하지 않았다.

## 11. 콘텐츠 권한

등록 화면에 “기관이 이용 권한을 보유했거나 공식적으로 임베드가 허용된 영상만 등록해 주세요.”를 표시하고 영상·음원과 가사 권한을 각각 확인한다. 시스템이 방송 영상을 복사하거나 노래 가사를 수집하지 않는다.

권한 체크박스는 이용 허가를 대신하지 않는다. 기관이 사용 범위와 출처를 확인해야 한다. 임베드가 금지되거나 삭제된 영상은 실패 안내를 표시하며 다운로드·재업로드로 우회하지 않는다. 지원 API는 [YouTube 공식 IFrame Player API](https://developers.google.com/youtube/iframe_api_reference)를 사용한다.

## 12. 검증 및 남은 범위

검증에는 직접 만든 6초짜리 단색 영상과 테스트 음을 사용했다. 실제 드라마·노래·가사는 테스트나 배포에 포함하지 않는다. 필요하면 `node tests/make-bori-media-fixtures.cjs`로 생성한다. 로컬 FFmpeg 경로는 `FFMPEG_PATH`로 지정할 수 있다.

- 단위 검사: URL·권한·가사 타이밍/겹침·추천·개인 기록 검증.
- API 검사: 인증, 메타데이터 CRUD/사용 중지/보관 삭제, 로컬 파일 서버 등록 차단, 중복·오래된 감상 기록 방지, 공개 응답 개인정보 제외. PostgreSQL 트랜잭션 대역 검사이며 실DB 검사는 아니다.
- 브라우저 검사: 업로드 MP4/WAV 실제 재생·종료, 자동 다음 OFF, 회상·기분·일지, 가사·배속·멈춤·복구·반복·중단, 개별 대상자 반응.
- 오후 편성 검사: 해당 보리 페이지 연결, 3분 교체 없음, 부모 일시정지, 감상 내용을 포함한 단일 수업 일지.
- 오류 검사: 없는 영상에서 재시도·다른 영상·홈 안내.
- YouTube는 API 대역으로 컨트롤/종료/반복을 검증했다. **실제 기관 공식 영상의 임베드 허용 여부와 재생은 자료 등록 후 확인해야 한다.**
- 반응형: PC 1920/1366, 태블릿 768, 모바일 390 폭. 기존 메인 및 네 캐릭터 방 회귀 검사 포함.
- 관리자 UI: 영상/노래 추가, 수정 시 순서 유지, 사용 ON/OFF, 순서 변경, 메모의 일지 반영, 삭제 후 기록 보존 검증. 인증된 선생님 공간 재진입도 확인.
