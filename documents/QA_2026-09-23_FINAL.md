# 디지털 AI 학교 6차 QA

## 범위와 환경
- 메인, 콩이, 토리, 나비, 보리, 집 꾸미기, 오늘의 20분 활동: 7페이지.
- Edge/Chromium: 1920×1080, 1600×900, 1366×768, 1024×768, 768×1024 (35조합). 관련 기존 테스트는 390/320px 모바일도 포함.
- 새 기능 추가 없이 화면 완성도 수정. Google 설정/비밀값/음성 매핑/활동 데이터 변경 없음.

## 확인 결과
- 메인: 네 캐릭터 우선 표시, 중복 진입 영역 접힘, 전체 활동/디지털 배우기/기록/선생님 공간 왕복 정상.
- 상단: 어르신 직접 메뉴 5개. 글씨/고대비/소리 설정 및 선생님 링크 정상.
- 운동: 준비/진행/완료 분리, 초기 완료 숨김, 10개 실제 완료 조건, 이전/일시정지/재생/다음, 기록 보존 정상. MP4/WebM 테스트 영상 및 이미지 fallback 정상.
- 토리/나비/보리: 기존 총 12개 활동에서 선택한 한 활동만 표시, 완료/재시도/다른 활동/오래된 콜백 취소 정상.
- 집 꾸미기: 쉬운 모드 7단계의 한 종류씩 선택, 벽지 즉시 변경, 저장/재진입 정상. 자유 모드 가구/의상/되돌리기/저장 회귀 테스트 통과.
- Google TTS 운영 실호출: 4캐릭터 모두 HTTP200 audio/wav. 콩이 Achird, 토리 Aoede, 나비 Gacrux, 보리 Charon 헤더 및 WAV 확인. 문장: “천천히 함께해요.”. 음색의 주관적 청취 평가는 별도.
- 음성 전환: 테스트 WAV로 네 캐릭터를 빠르게 전환했을 때 이전 3개 취소, 마지막 종료, 동시 재생 최대 1개. 운동 자막·지연 응답·일시정지·재개 검증 통과.
- 이미지: 보이는 broken image 없음. 캐릭터 contain/전체 SVG 및 운동 미디어 유지. 내부 HTML 링크 49개 대상 파일 존재, 주요 버튼 동작 테스트 통과.
- 35 화면 조합: 가로 넘침/보이는 텍스트 잘림 없음. 최종 7페이지 재점검에서 로컬 HTTP4xx/5xx 및 pageerror 없음.
- 외부 네트워크: 로컬 브라우저의 ERR_NETWORK_ACCESS_DENIED는 검사 환경 제한. 별도 네트워크 확인에서 Google Fonts, YouTube 썸네일 2개, Open-Meteo 모두 HTTP200.

## 수정한 부분
1. 낮은 높이의 PC에서 메인 여백과 캐릭터 표시 높이 조정. 1366×768에서 오늘의 20분 활동 시작 버튼 하단 약 704px로 첫 화면에 표시.
2. 학교 안내 펼침 영역 폭 및 한국어 버튼 줄바꿈 보강.
3. 나비 날짜 keep-all 적용으로 “23일”의 “일”만 따로 떨어지지 않게 수정.
4. 7페이지 탭 아이콘 지정으로 자동 favicon.ico 404 요청 방지.
