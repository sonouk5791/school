# 디지털 AI 학교 오늘의 작업 정리

작성일: 2026-09-22

## 홈페이지와 접근성
- 콩이·토리·나비·보리를 중심으로 메인 화면을 정리했습니다.
- 중복 활동 진입 카드를 통합하고 오늘 추천 활동을 간결하게 배치했습니다.
- 상단 메뉴를 단순화하고 글자 크기·고대비·천천히 듣기를 보기 메뉴로 모았습니다.
- 어르신 화면과 선생님 공간을 구분했습니다.
- 체조 이미지 잘림과 한글 안내문이 좁게 줄바꿈되는 문제를 수정했습니다.

## 캐릭터 활동방
- 토리 놀이방, 나비 학습방, 보리 취미방에서 선택한 활동 하나에 집중하도록 정리했습니다.
- 활동 선택 → 진행 → 완료 화면을 분리했습니다.
- 콩이 운동방은 시작 전·운동 중·완료 후로 나누고 중복 시작 버튼과 조기 완료 표시를 정리했습니다.
- 기존 문제, 운동 콘텐츠, 활동 기록과 페이지 연결을 유지했습니다.

## 캐릭터 방 꾸미기
- 캐릭터를 크게 배치하고 따뜻한 방과 가구가 잘 보이도록 개선했습니다.
- 큰 점선 타원을 없애고 발밑의 약한 그림자로 정리했습니다.
- 오늘의 코디 설명을 실제 착용 모습과 맞추었습니다.
- 선택한 의상·색상·소품·가구가 바로 보이도록 개선했습니다.
- 쉬운 꾸미기는 한 번에 한 질문과 3~4개 선택지를 보여줍니다.
- 자유 꾸미기, 저장·불러오기, 초기화 확인 기능을 유지했습니다.

## 오늘의 20분 활동
- 콩이 운동 → 토리 놀이 → 나비 학습 → 보리 취미 순서로 기존 활동을 연결했습니다.
- 현재 단계 표시, 다음 활동 이동, 중간 종료 후 이어하기를 추가했습니다.
- 전체 활동을 마친 뒤에만 완료 화면이 나타나도록 구성했습니다.

## 캐릭터 표현과 음성
- 기존 얼굴·의상·색상과 캐릭터 정체성을 보존했습니다.
- 미세한 호흡, 눈 깜빡임, 손 인사, 말할 때 입모양 변화를 연결했습니다.
- 네 친구가 같은 교실에 서 있는 느낌의 크림색 벽과 베이지색 바닥을 적용했습니다.
- 캐릭터 발 위치와 그림자를 맞추고 개별 흰 카드 느낌을 줄였습니다.
- 네 캐릭터의 서로 다른 목소리 재생을 운영 화면에서 확인했습니다.
- 소리 켜기·끄기와 중복 재생 방지를 유지하고 음소거 안내를 쉽게 정리했습니다.

## 확인 및 보존
- 관련 자동 검사와 브라우저 검사를 진행했습니다.
- 네 캐릭터 음성의 재생 완료를 확인했으며 해당 검사에서 콘솔 오류가 없었습니다.
- 기존 캐릭터 이미지, 운동·놀이·학습·취미 콘텐츠, 저장된 활동 데이터는 유지했습니다.
- 이번 정리본은 화면·기능·사용 경험과 검증 결과만 담았습니다.
- 이번 요청은 GitHub 추가 푸시 없이 Vercel 배포로 반영합니다.
