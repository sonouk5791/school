# 메인 마을 배경과 공간 연결 개선

- 연한 크림·연두 바탕에 완만한 잔디 언덕, 작은 관목과 화단을 배치했다.
- 기존 고정 배경 길 대신 실제 집 앞마당 위치를 측정해 중앙 쉼터와 연결하는 곡선 길을 그린다. 화면 크기 변경 시 ResizeObserver로 갱신한다.
- 모바일은 왼쪽 산책길과 집 앞 짧은 연결 길로 이어져 제목과 설명 뒤를 가로지르지 않는다.
- 중앙 쉼터에 둥근 잔디 공간, 크기가 다른 두 나무, 벤치와 작은 꽃을 더했다.
- 콩이 마당의 운동 매트, 토리의 꽃 장식, 나비의 정돈된 화단, 보리의 벤치를 추가했다. 기존 공·퍼즐·책·음표를 보존했다.
- 캐릭터 아래 잔디와 옅은 접지 그림자, 부드러운 버튼 테두리와 말풍선 색으로 주변 공간을 연결했다. 캐릭터 PNG/SVG 원본·얼굴은 변경하지 않았다.
- 제목은 “친구들 마을에 오신 것을 환영해요”로 변경했다. 소개 종료 후에도 산책 안내 문구를 유지한다.
- 장식은 aria-hidden, pointer-events:none으로 설정하여 키보드·클릭·안내 기능을 방해하지 않는다. 고대비 모드는 어두운 배경과 밝은 글씨를 유지한다.

## 보존 범위

인사영상 및 실제 ended 전환, 네 캐릭터 소개, 기존 방 URL, 우리 집·이웃집·오늘의 수업·꾸미기 연결, Google/Gemini TTS, 저장 데이터와 관리자 기능을 유지한다. 이번 변경은 메인 화면 표현에 한정한다.

## 검증

- 기존 village-walk 검사: 1920×1080, 1366×768, 768×1024, 390×844. 말풍선 겹침·잘림, 가로 넘침, 64px 버튼, 투명 집 영역, 장식 클릭 차단과 브라우저 오류 검사 통과.
- 기존 home-autoplay 검사: 자동재생·소리 재시작·실제 종료 전환·네 소개·방 이동·복귀·다시 보기·건너뛰기·영상 오류 대응 통과.
- JS 구문 검사와 기존 미디어 manifest 빌드 통과.
- 실제 모바일 기기 시험이 아닌 Edge 브라우저의 화면 크기별 검사다.

## 주요 파일

- js/village-landscape.js: 장식 풍경 및 반응형 길 좌표
- css/home-welcome-flow.css: 배경·마당·쉼터·버튼 표현
- js/home-welcome-flow.js: 장식 연결 및 안내 문구
- index.html: 새 장식 스크립트 및 캐시 버전
- tests/village-walk.cjs: 기존 검사에 콘솔 오류·장식 클릭 차단 검증 추가
