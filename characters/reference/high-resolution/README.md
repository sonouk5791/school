# 고해상도 공식 입모양 제작

사용자 최신 요청에 따라 내장 image_gen 도구로 디자인 참고 JPEG에서 새로 제작했습니다. 이전 저해상도 시트의 픽셀을 잘라 확대하지 않았습니다.

- 최종 파일: `public/characters/{id}/mouth/{id}_{a,e,i,o,u}.png`
- 원본 생성 크기/최종 크기: 1254 × 1254px, RGBA PNG, 투명 배경.
- 캐릭터별 아 기준 렌더를 고정하고 에/이/오/우 생성 결과의 입 주변만 8px 경계 블렌딩으로 합성합니다. 눈/눈썹/코/안경/머리/몸/의상/실루엣/알파 채널은 기준 렌더의 픽셀을 유지합니다.
- 이는 새 렌더의 5개 프레임 사이 일관성을 뜻합니다. 생성형 재제작이므로 참고 JPEG와 픽셀 단위로 동일한 복원은 아닙니다.
- `raw/`: 도구 원본 출력. `build.json`: 최종 크기, 입 영역, 제작 방법. `prompts.json`: 사용한 편집 프롬프트.
- `../../../scripts/build-hd-characters.cjs`: 원본 재생성이 필요 없는 재현 가능한 합성/경로 연결.
- `../../../tests/official-character-assets.py`: 20개 파일/서로 다른 입/입 외부 픽셀 고정/알파 경계 검사.
- 학교는 일반 정적 서버로 public 폴더를 자동 마운트하지 않으므로 데이터 URL에 `/public/characters/`를 명시합니다. 기존 `/characters/`와 `friend-*.png`는 호환용 같은 고해상도 파일로 유지합니다.
- 기본 표정은 시트의 마지막 열과 같이 우 입모양입니다. 별도의 닫힌 입은 이번 20장에 포함되지 않습니다.
- 이전 동작 시트에서 분류한 별도 포즈는 별도 자료이며 이번 고해상도 입모양 제작 범위에 포함하지 않습니다.
