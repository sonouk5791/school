# 실시간 캐릭터 꾸미기 (2026-09-22)

## 구현
- `js/character-customizer.js`: 기존 캐릭터 PNG 위에 SVG 레이어를 합성한다. 원본 파일은 수정하지 않는다.
- 의상 6종(운동복, 니트, 가디건, 조끼, 잠옷, 외출복), 상의/하의/신발/포인트/안경 색상 6색, 액세서리 6종, 표정 4종, 소품 6종.
- 원본 옷 영역을 캐릭터별 경로로 제한해 색을 변경하고, 직물 무늬·여밈·칼라 등 옷 종류별 장식을 합성한다. 신발·액세서리·소품은 SVG 도형 레이어다. 3D 모델 자체를 변형하는 방식은 아니다.
- 표정은 기존 고해상도 입모양 이미지와 새 눈 감은 이미지의 눈 영역만 합성한다. 콩이 안경 해제는 안경 없는 얼굴 패치를 부드러운 마스크로 합성한다. 토리의 열린 오른쪽 눈은 원본 왼쪽 눈을 대칭 합성한다.
- 기본 상태는 원본 PNG 한 장만 표시한다. 기본 모습으로 되돌리면 모든 변경 레이어가 사라진다.
- 한 종류에 4~6개 선택지를 제공한다. 액세서리는 다시 누르면 벗는다. 소품은 내려놓기 버튼으로 해제한다.
- 완료 화면에도 실제 현재 커스터마이징 결과가 표시된다.

## 저장 및 호환
기존 `senior_character_house_data_v1`에 `customizations` 맵을 추가했다. 각 캐릭터는 outfit, topColor, bottomColor, shoeColor, accentColor, glassesColor, accessories[], expression, prop을 갖는다. 기존 방 구조·가구·outfit 기록은 삭제하지 않는다. 과거 텍스트 선택 기록은 실제 착용 에셋이 아니므로 새 커스터마이징 상태가 없으면 원본으로 시작한다. 저장하기와 이어 꾸미기로 새 결과를 복원한다. 기본 모습 되돌리기는 캐릭터만 변경하며 가구는 유지한다. 되돌리기 이력에도 커스터마이징이 포함된다.

## 생성 이미지 출처
내장 image_gen을 사용했다. 원본 디자인은 `assets/images/friend-{id}.png`를 참조했다.
- kongi-no-glasses.png: 안경만 제거하고 얼굴·눈·체형·노란 의상·구도를 유지하라는 편집 프롬프트.
- {kongi,tori,nabi,bori}-closed-eyes.png: 두 눈만 부드럽게 감고 나머지 얼굴·몸·의상·정렬·투명 배경을 유지하라는 편집 프롬프트.
- 생성본 전체로 원본을 대체하지 않고 필요한 얼굴 영역만 사용한다. 신규 자산은 이 폴더에 저장했다.

## 검증
`tests/character-customizer.cjs`: 네 캐릭터의 종류별 변경, 실제 미리보기 픽셀 차이, 기본 레이어 완전 복원, 저장/재접속 복원, 1024/768/390px 화면.
`tests/character-house-layout.cjs`: 1440/1024/768/390px의 기존 가구 추가·벽지·되돌리기·저장 복원.

전역 안내 캐릭터와 공식 원본 디자인은 유지한다. 사용자의 최신 요청에 따라 집 꾸미기 화면에서만 의상색·안경 해제·표정 등 변경을 허용한다.
