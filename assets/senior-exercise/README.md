# 디지털 AI 학교 어르신 체조

## 결과
- 진입: `/senior-exercise.html`, 홈페이지 상단 메뉴/주요 활동/기존 체조 화면의 새 링크.
- 재생 형태: 첨부 그림 5장과 한국어 음성이 이어지는 브라우저 슬라이드 콘텐츠. 관절이 움직이는 영상이나 MP4 파일은 아닙니다.
- 전체 184초(3분 4초), 6개 장면, 짧은 자막 50개.
- 기본 재생 속도 0.8로 생성한 한국어 여성 음성(HeyGen `fe3fbd12d84c41b5a791e6ea544f774d`). 숫자 발음이 끝난 뒤 2.3초 쉼. 충분한 발화/쉬는 시간을 보장하여 요청서의 약 8/30/35초보다 일부 장면이 길어졌습니다.
- 느린 피아노 유사 반주는 직접 합성했으며 음성보다 작은 음량으로 믹싱. 정규 피아노 녹음은 아닙니다.

## 이미지 원본과 보완
- `intro.png`: 첨부 `오전 11_46_04 (1).png`.
- `neck.png`: 첨부 `오전 11_46_04 (2).png`.
- `arms.png`: 첨부 `오전 11_46_05 (3).png`는 왼쪽 3명/오른쪽 4명으로 총 7명. 요청서의 8명 조건을 맞추기 위해 내장 image_gen으로 왼쪽 팔 올리기 보리를 보완했습니다. 원본은 `source/arms-original-seven.png`에 보존.
- `legs.png`: 첨부 `오전 11_46_05 (4).png`.
- `breathing.png`: 첨부 `오전 11_46_05 (5).png`.
- 5장 모두 1672×941px. 16:9 컨테이너에서 object-fit:contain으로 전체를 보존합니다. 줌은 98%→100% 이내여서 이미지가 잘리지 않습니다.
- 편집 프롬프트 요지: 기존 방/한글 제목/부제/네 캐릭터 외형과 색상을 유지하고, 왼쪽 팔 올리기 4명(콩이·토리·나비·보리), 오른쪽 박수 4명으로 정확히 8명 구성. 의자와 신발 전체 노출.

## 재생 구현
- 단일 녹음 오디오의 currentTime으로 이미지/자막/숫자/진행률을 동기화. 버퍼링·일시정지 시 그림 진행도 정지.
- 녹음은 시작 클릭 후 재생하며 이후 장면 자동 전환. 숫자 표시는 발화 시작과 연결.
- 이전/다음은 재생 중이면 이어 재생, 정지 상태이면 정지 유지. 처음부터 버튼은 재생을 시작.
- 전체화면 API 미지원 시 화면 확대 모드와 나가기/Escape 제공.
- 페이지 숨김/이탈 시 음성 정지. prefers-reduced-motion에서는 줌과 교차 페이드 제거.
- `script.json`: 요청 대본. `source/speech.json`: 생성 음성/단어 시간 정보. `program.json`: 최종 타임라인. `captions-ko.vtt`: 음성 대본 자막.
- 제작 스크립트: `scripts/build-senior-exercise.py`. 최종 mp3 외 제작용 WAV 및 원본 기록은 Vercel 업로드 제외.
- 원래의 20분 체조 영상/음성 검토 자료는 별도로 보존.

## 안내 근거와 범위
흔들리지 않는 의자, 편안한 범위의 움직임, 불편할 때 쉬기 등의 기본 안내를 넣었습니다. 개인 상태에 맞춘 운동 처방이나 치매 치료 효과를 보장하는 프로그램은 아닙니다. 출처: [NHS 앉아서 하는 운동](https://www.nhs.uk/live-well/exercise/sitting-exercises/), [NHS 고령자 운동 안내](https://www.nhs.uk/live-well/exercise/physical-activity-guidelines-older-adults/).
